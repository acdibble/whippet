# Hotkeys for apps and commands

Raycast lets any application or command have its own global hotkey, which is one of its most-used features.

## Done when

- [x] A Shortcuts pane in Settings lists commands and installed applications, each with a hotkey recorder
- [x] Applications can be filtered by name
- [x] An application hotkey opens the app; a command hotkey opens Whippet in that command
- [x] Hotkeys survive relaunches and apps moving folders

## Notes

A Shortcuts pane in Settings uses KeyboardShortcuts recorders, with named shortcuts keyed by bundle identifier for apps. Commands: Calculator, Clipboard History and Settings.
