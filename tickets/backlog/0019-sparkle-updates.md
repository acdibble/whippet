# Automatic updates with Sparkle

Without an updater, everyone stays on the version they downloaded.

## Done when

- [ ] Sparkle checks an appcast feed and installs updates
- [ ] Updates are signed with Sparkle's EdDSA key, kept out of the repo
- [ ] Check for Updates is in the menu bar menu and Settings

## Notes

Host the appcast and DMGs on GitHub Releases or a site.
