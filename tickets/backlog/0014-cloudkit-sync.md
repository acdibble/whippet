# Sync history with CloudKit

Sync clipboard history, pins and calculator history across Macs.

## Done when

- [ ] Changes appear on another Mac signed into the same iCloud account
- [ ] Clipboard contents use CloudKit encrypted fields
- [ ] Image sync can be turned off

## Notes

Blocked on the paid Apple Developer membership. Use `CKSyncEngine`.
